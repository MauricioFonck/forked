# FORKED v0.1.0a1 — first public alpha

> **Pre-alpha research runtime, published as a GitHub pre-release on 2026-11-22.** Not on PyPI. Read
> [Guarantees and limits](../guide/05-guarantees-and-limits.md) before relying on any of it, and
> [the prior-art matrix](../15-prior-art-matrix.md) before describing what is new about it.

## What it is

A local-first runtime for **controlled counterfactual experiments** on instrumented workflows and
AI-agent executions: record a run, replay it from its recorded observations, fork it at a tool call
with one declared change, keep every side effect **denied by default**, compare the two runs with
invariants that are `verified`, `violated` or `unknown`, and export evidence anyone can verify
offline. It runs entirely on your machine: no network, no cloud, no API key.

## What is in this alpha

| Area | You get |
|---|---|
| Recording | Typed, ordered events; secrets redacted before they touch disk; oversized payloads omitted with a digest (never truncated); an unfinished run is reported `incomplete` |
| Replay | Strict replay from recorded observations; nothing executes; any call it cannot answer fails closed |
| Branches | One intervention type (replace a tool result) at a checkpoint (a `tool.call` sequence); default-deny effect policy `default-deny/1` |
| Comparison | Step-by-step diff, outcome changes, five invariants, claim level `observational` or `controlled_comparison`; never causal, no score |
| Evidence | Deterministic `forked-evidence/1` package; `forked verify` separates integrity from validity and rejects a forged manifest even when its hashes are fixed |
| Integrations | Python SDK; Pydantic AI and LangGraph adapters (optional extras); OpenTelemetry export/import (OTLP/JSON) |
| Benchmark | FCRB: ten scenarios, two executed baselines (plain logs; LangGraph time travel for S04), capture overhead — **provisional** |
| Prior art | [A first-pass matrix](../15-prior-art-matrix.md): what already exists, with sources, dates and confidence |
| Docs and examples | [User guide](../guide/01-getting-started.md), [`examples/`](../../examples/README.md), [`benchmarks/`](../../benchmarks/README.md) |

Formats: event schema `0.1.0` (published in `spec/cip/v0.1/`, with golden fixtures), package format
`forked-evidence/1`. Python 3.11–3.14; Linux, macOS and Windows are tested in CI.

## What it is not

* Not general deterministic replay, and not an OS or process snapshot.
* Not a sandbox: only tool calls routed through the SDK are observed.
* Not a causal-inference engine: one run pair never supports a causal claim.
* Not signed: evidence integrity is internal consistency, not authorship.
* Not production software, and not on PyPI.

## Known limitations

* The CLI's `record`, `replay` and `branch` drive the built-in demo; your own workflows use the SDK.
* Pydantic AI and LangGraph: model calls (and LangGraph's other nodes and state) are not recorded; replay
  re-runs the agent, so a real LLM usually diverges and the replay fails closed. LangGraph results are the
  text LangGraph produces, and a replayed result carries content only.
* One intervention type, one effect policy, one experiment per evidence package.
* Capture costs roughly 2–3 ms per tool call (author's Windows machine).
* The benchmark uses toy, scripted workflows and has **not been independently reproduced**.
* **Prior art:** recording, replaying from observations, replacing a tool result, hashing and redaction
  are already done by others. FORKED's claimed difference is a *combination* (effect policy, honest
  invariants, evidence whose validity is recomputed offline), limited to what the first-pass review
  read; the review is **partial** (OpenInference, W3C Trace Context, OCI/in-toto and patents are not yet
  covered). Treat FORKED as a proposal and a hypothesis, not as a first or a standard.

## Try it

Python 3.11–3.14. Not on PyPI yet: install from the source or the wheel attached to this release.

```bash
git clone https://github.com/MauricioFonck/forked && cd forked
uv sync --locked
uv run forked record toy-agent
uv run python -m examples.minimal_sdk
uv run python -m benchmarks.fcrb --out results/
```
